Key Takeaways

• Cognition includes thinking, memory, language, and problem-solving.
• Memory consists of encoding, storage, and retrieval.
• Working memory temporarily holds and processes information.
• Long-term memory includes explicit and implicit memory.
• Thinking relies on concepts, algorithms, heuristics, and problem-solving strategies.
• Language influences communication and cognition.
