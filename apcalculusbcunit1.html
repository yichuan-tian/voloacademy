Key Takeaways

• A limit describes the value a function approaches as x approaches a point.
• Limits can be evaluated graphically, numerically, algebraically, or analytically.
• A function is continuous if there are no breaks, holes, or jumps.
• Types of discontinuities include removable, jump, and infinite discontinuities.
• The Intermediate Value Theorem (IVT) guarantees a function reaches every value between two endpoints if it is continuous.
